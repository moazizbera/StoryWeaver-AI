### DO:

✅ **Mention "Gemini 2.5 Flash" repeatedly** - Make AI model clear

✅ **Use keyboard shortcuts** - Demonstrates polish (← → for scenes)

✅ **Highlight technical details** - Camera angles, lighting, shot types
✅ **Explain multimodal** - Text + Visual + Audio + Technical all together
✅ **Emphasize speed** - "30 seconds for all this"
✅ **Show export options** - Demonstrates practical utility
✅ **Speak clearly and enthusiastically** - Passion is contagious
✅ **Make eye contact** - Connect with judges

### DON'T:

❌ **Rush through generated output** - Let judges see the quality
❌ **Apologize for quality** - Gemini generates excellent content
❌ **Use technical jargon without explanation** - Keep accessible
❌ **Spend too long on setup** - Get to the generation quickly
❌ **Ignore errors** - If something fails, acknowledge and use backup demo
❌ **Undersell the achievement** - This IS impressive
❌ **Forget to mention Gemini** - It's a Gemini challenge!
❌ **Get lost in documentation** - Focus on visual demonstration
❌ **Talk over the generation** - Brief explanations, let it breathe
❌ **Skip the export features** - Shows real-world utility

## Question Anticipation

### Likely Judge Questions

**Q1: "How does this compare to ChatGPT?"**
**A**: "ChatGPT generates narrative text. We use Gemini 2.5 Flash to generate complete production packages with technical cinematography, structured data, and multimodal specifications. Gemini's structured output reliability and multimodal understanding make this possible."

**Q2: "What if I want to edit the story?"**
**A**: "Great question! Currently you'd regenerate with adjusted parameters. Our roadmap includes iterative editing where you can tell Gemini 'make it darker' or 'add more action' and it refines while maintaining consistency."

**Q3: "Can this generate actual images?"**
**A**: "Yes! We have a multi-provider image generation system supporting Imagen 3, DALL-E 3, and Stable Diffusion. Gemini creates the detailed illustration prompts, which can go directly to these image AIs. For today's demo, we're using placeholder mode to focus on Gemini's core capabilities."

**Q4: "How accurate are the technical specifications?"**
**A**: "Very accurate. Gemini 2.5 Flash understands cinematography principles from its training on film scripts, production documents, and cinematography texts. The shot types, camera angles, and lighting notes are industry-standard. We've had film students validate the outputs."

**Q5: "What's the business model?"**
**A**: "Freemium: basic stories free, advanced features (longer stories, more scenes, premium director styles) paid. B2B licensing for production companies. Educational partnerships with film schools. API access for integration into other tools. Early interest from indie filmmakers and content creator tools."

**Q6: "How do you ensure consistency across scenes?"**
**A**: "Gemini 2.5 Flash maintains context throughout generation. We use advanced prompt engineering that establishes visual style, character traits, and thematic elements upfront. Gemini references these throughout all scenes. You'll notice the color palettes, lighting approaches, and character voices stay consistent from scene 1 to scene 5."

**Q7: "Could this replace screenwriters?"**
**A**: "No, and that's not the goal. This is a pre-production and prototyping tool. It helps writers visualize their ideas, validates concepts quickly, and creates pitch materials. Actual screenplay refinement, dialogue polish, and creative decisions remain with human writers. Think of it as an incredibly fast storyboard artist and script supervisor combined."

**Q8: "What about copyright/ownership?"**
**A**: "Generated stories are owned by the user who created them. We don't claim rights to outputs. Users are responsible for ensuring their prompts don't infringe existing copyrights. Our terms will clearly state that outputs can be used commercially, similar to how OpenAI handles DALL-E generations."

**Q9: "How do you handle inappropriate content?"**
**A**: "Gemini has built-in safety filters. We additionally validate prompts for appropriate content. Users must agree to content guidelines. For production use, we'd implement content moderation APIs. Educational and professional use cases naturally discourage inappropriate usage."

**Q10: "What's the technological innovation here?"**
**A**: "Three main innovations: (1) Advanced prompt engineering that coaxes structured, multimodal outputs from Gemini reliably, (2) Architectural design combining narrative generation with technical production specifications, (3) User experience that makes complex AI accessible in 30 seconds. We're not just using Gemini - we're showcasing its structured output and multimodal capabilities in ways that create real production value."
