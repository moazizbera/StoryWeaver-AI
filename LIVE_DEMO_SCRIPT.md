## 🎬 Recording Tips

### **Before Recording:**
1. **Clear browser history** for clean localStorage
2. **Close unnecessary tabs** to avoid distractions
3. **Disable notifications** (Windows Focus Assist)
4. **Test audio levels** if narrating
5. **Practice the flow** once (dry run)

### **During Recording:**
1. **Speak clearly and slowly** - give time for features to load
2. **Use mouse smoothly** - highlight important elements
3. **Pause at key moments** - let viewers absorb information
4. **Scroll slowly** - show all content clearly
5. **If mistakes happen** - pause recording, resume, and edit later

### **Camera/Screen Settings:**
- **Resolution**: 1920x1080 (Full HD) minimum
- **Frame Rate**: 30fps or 60fps
- **Browser Zoom**: 100% (default)
- **Window Mode**: Full screen or maximized window

### **Recommended Tools:**
- **OBS Studio** (Free, professional, multi-platform)
- **Windows Game Bar** (Win+G - built into Windows 10/11)
- **Loom** (Easy screen + webcam recording)
- **Camtasia** (Professional paid option)
- **ScreenFlow** (Mac users)
